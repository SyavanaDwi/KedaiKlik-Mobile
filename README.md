# KedaiKlik Management System Mobile

A mobile application built with React Native and Expo to help restaurant
staff manage daily operational activities directly from their mobile
devices.

## Overview

KedaiKlik Management System Mobile is designed for restaurant staff to
monitor incoming orders, view order details, update order statuses, and
track payment information while away from a desktop computer.

The application connects to a backend REST API to retrieve and manage
operational data, providing staff with a more flexible way to handle
restaurant activities.

## Key Features

-   **Operational Dashboard:** Access restaurant operational information
    from a mobile interface.
-   **Order Monitoring:** View incoming orders.
-   **Order Details:** Review information about individual orders.
-   **Order Status Management:** Update order statuses.
-   **Payment Information:** View and track payment details.
-   **API Integration:** Communicate with the backend through REST API
    endpoints.

## Tech Stack

  Category                  Technologies
  ------------------------- --------------
  Mobile Framework          React Native
  Development Platform      Expo
  Programming Language      TypeScript
  Backend                   Express.js
  Database                  PostgreSQL
  ORM                       Prisma ORM
  Real-Time Communication   Socket.IO

## Application Workflow

1.  Restaurant staff sign in to the mobile application.
2.  Staff access the operational dashboard.
3.  Staff monitor incoming orders and open order details.
4.  Staff update order statuses and review payment information.
5.  The application communicates with the backend API to exchange
    operational data.
